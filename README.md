# Практические навыки загрузки Linux

Практическая работа посвящена загрузке Linux, восстановлению доступа к системе без знания пароля администратора, работе с LVM и созданию собственного модуля для `initrd`.

## Окружение

- **Операционная система:** CentOS Linux 7 (Core)
- **Ядро:** Linux 3.10.0-1160.el7.x86_64
- **Загрузчик:** GRUB2
- **Initramfs:** `initrd` / `initramfs`
- **Виртуализация:** VirtualBox (или другая система виртуализации)
- **LVM:** используется для управления дисковой разметкой

# Загрузка Linux и редактирование параметров GRUB

Для изменения параметров загрузки необходимо открыть графический интерфейс VirtualBox (или другой системы виртуализации), запустить виртуальную машину и во время выбора ядра Linux нажать **`e`** (`edit`).

После этого открывается конфигурация загрузки GRUB2:

<img width="1023" height="768" alt="изображение" src="https://github.com/user-attachments/assets/e78da366-b435-4c4a-8c90-33d41a3741fa" />

Основные параметры загрузки находятся в строке, начинающейся примерно так:

```text
linuxefi /vmlinuz-... root=... ro ...
```

В эту строку можно временно добавить или изменить параметры ядра.

Для запуска с изменёнными параметрами используется:

```text
Ctrl + X
```

Изменения, сделанные таким способом, являются временными и относятся только к текущей загрузке.
